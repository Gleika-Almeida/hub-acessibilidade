# Hub Acessibilidade Digital

Hub de Acessibilidade Digital para análise automatizada de interfaces HTML com base em critérios relacionados à WCAG.

## Sobre o projeto

O Hub Acessibilidade é uma aplicação desenvolvida para ajudar pessoas desenvolvedoras e designers a identificar problemas estruturais de acessibilidade em interfaces web.

O usuário pode inserir um código HTML e receber um relatório automatizado com pontuação, severidade, critérios WCAG relacionados e recomendações de correção.

> A análise automatizada não substitui uma auditoria manual completa de acessibilidade.

## Funcionalidade implementadas

- Análise de código HTML
- Verificação de idioma da página
- Verificação de título
- Análise da hierarquia de titulos
- Indentificação de títulos
- Identificação de titulos vazios
- Verificação de imagens sem atributo `alt`
- Identificação de campos sem rótulo acessível
- Verificação de botões sem nome acessível
- Verificação de links sem nome acessível
- Validação de referências `aria-labelledby`
- Validação de referências `aria-describedby`
- Cálculo de pontuação de acessibilidade
- Classificação dos problemas por severidade
- Relatório com critérios WCAG
- Recomendações de correção
- Interface responsiva e navegável por teclado
- Testes automatizados no backend
- Testes automatizados no frontend
